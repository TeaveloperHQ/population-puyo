# 인구 문제 카드 — 디자인 에셋

뒤집기 대결 게임(네트워크)용 카드 디자인. 게임 로직·통신은 이 폴더에 없음.

## 파일
| 파일 | 내용 |
|---|---|
| `tokens.css` | 색·글꼴·애니메이션 변수 |
| `card.css` | 카드 컴포넌트 스타일 (tokens.css 다음에 로드) |
| `cards.js` | 카드 데이터 + `PopCards.cardHTML()` 등 마크업 헬퍼 (브라우저 전역) |
| `cards.json` | 같은 카드 데이터 (서버에서 쓸 때) |
| `icons/` | 인구 피라미드 아이콘 2종 (`currentColor`) |
| `images/` | 그림 카드용 이미지 2장 (c05) |
| `preview.html` | 디자인 확인용 페이지. 브라우저로 바로 열면 됨 |

글꼴: Google Fonts `Black Han Sans`(제목·덮개 ?), `Gothic A1` 500/700/800(카드).

## 카드 규칙
- 카드 1장 = 앞면 `dev`(선진국) + 뒷면 `ing`(개발도상국). 10종 × 2벌 = 20장 (`PopCards.deck()`).
- 카드 비율 5:7. 크기는 부모 너비를 따르며 내부 요소는 컨테이너 쿼리(`cqw`)로 비례 조정됨. 그리드 칸에 넣기만 하면 됨.
- 면 전체를 진영 색으로 칠하는 것이 핵심 (멀리서도 어느 색이 많은지 보이게). 남색/주황은 밝기 차이도 커서 색약 구분 가능.

## 상태 (모두 data 속성)
| 속성 | 값 | 의미 |
|---|---|---|
| `data-side` | `dev` / `ing` | 위로 보이는 면. 바꾸면 300ms 뒤집기 애니메이션 |
| `data-hidden` | `true` / `false` | 시작 전 덮개 표시 |
| `data-locked` | `true` | 게임 종료 후 커서만 기본으로 (입력 차단은 로직에서) |
| `data-card-id` | `c01`~`c10` | 카드 종류 |
| `data-index` | `0`~`19` | 보드 위치 (동기화 키로 쓰기 좋음) |

네트워크 동기화 시에는 카드를 다시 그리지 말고 `PopCards.setSide(el, side)`로 `data-side`만 바꾸면 됨.

## 입력 팁
두 사람이 한 화면에서 동시에 누를 수 있으면 `click` 대신 `pointerdown`에서 뒤집는 게 반응이 빠름.
